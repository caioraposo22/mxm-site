# MXM — Site e orçamento 3D (protótipo)

- `/` — site de vendas da MXM (animação de entrada, linhas de produto, acabamentos, projetos, sustentabilidade, história, dúvidas).
- `/orcamento/` — configurador 3D de embalagens com pedido de orçamento pelo WhatsApp.
  Links diretos: `/orcamento/#cartucho`, `#delivery`, `#sacolas`, `#copo`, `#pote`, `#caixa-acai`.

Site estático, sem build. Conteúdos entre colchetes `[...]` ainda precisam ser confirmados pela MXM.
O número do WhatsApp da MXM fica na constante `MXM_WHATSAPP` em `orcamento/index.html`.
